❓ Help & FAQ

How do I chat?

Open AI Chat, type your question and press Send.

How do conversations work?

Each saved conversation has its own message history. Refreshing the app opens a clean New Chat, while saved conversations remain available in the list.

How does memory work?

Galaxy Core associates your browser with an anonymous profile ID and can synchronize memory with the backend.

Can I use images?

Yes. Multiple supported images can be uploaded together and analyzed.

Can I use voice?

Yes, if your browser supports speech recognition.

Why might a response fail?

Cloud services and AI model providers can occasionally experience temporary errors or delays.

Privacy

Galaxy Core is designed to keep the Gemini API key on the backend rather than exposing it to browser users.

Anonymous profile information may be used to associate cloud-memory data with the same browser profile.

Do not enter highly sensitive personal information unless the service's final privacy policy explains how it is handled.

Terms

Galaxy Core is an AI software service. AI-generated answers may contain errors and should be independently checked when accuracy is important.

Users are responsible for the information they submit and how they use generated content.
